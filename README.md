# 🚀 Meu Aprendizado em JavaScript

Bem-vindo ao meu repositório de estudos! Aqui estou registrando a minha evolução na programação web, organizando exercícios práticos e desafios lógicos à medida que domino os conceitos de JavaScript.

## 📚 Conceito Estudado: Estruturas Condicionais (if/else)
Recentemente estudei como o JavaScript controla o fluxo de um programa através de desvios condicionais. Aprendi a diferenciar:
- **Condição Simples:** Quando o bloco de código só executa se a resposta for verdadeira (usando apenas `if`).
- **Condição Composta:** Quando temos caminhos diferentes para respostas verdadeiras ou falsas (usando `if` e `else`).

---

## 🛠️ Projetos Desenvolvidos nesta Etapa

### 1. Sistema de Multas (Condição Simples)
Um site interativo que simula o funcionamento de um radar de trânsito do DETRAN.
* **O que faz:** Recebe a velocidade de um veículo em km/h. Se a velocidade ultrapassar o limite de 60 km/h, o sistema exibe uma mensagem em negrito alertando que o motorista foi multado.
* **Tecnologias:** HTML5 e JavaScript (Manipulação de DOM com `querySelector` e tratamento de dados numéricos).

### 2. Verificador de Nacionalidade (Condição Composta - Desafio Concluído!)
Site criado para resolver o desafio proposto no Curso em Vídeo.
* **O que faz:** O usuário insere o nome do país onde vive. O sistema analisa o texto: se for igual a "Brasil", exibe "Você é Brasileiro!". Caso contrário, exibe "Você é Estrangeiro!".
* **Tecnologias:** HTML5 e JavaScript (Uso prático de strings, operadores de igualdade e blocos `if/else`).
